# Source Hierarchy and Identity Protocol

## Default hierarchy

1. **Primary texts:** original works by Fukuyama and philosophers analyzed.
2. **Scholarly secondary sources:** peer-reviewed articles, scholarly monographs, university-press chapters.
3. **Institutional sources:** official statistics and reputable intergovernmental/research bodies for contemporary empirical claims.
4. **Scholarly reference sources:** SEP, IEP, academic encyclopedias.
5. **General/tertiary sources:** summaries, general sites, Wikipedia-derived documents; discovery only unless the claim is about the derivative itself.

## Authority rule

Use the relevant primary text to establish what an author argues. A secondary source may interpret or criticize; it does not replace the primary wording. A summary never outranks the full text.

## Duplicate/source identity record

For every apparent duplicate record title, author, edition, publisher/year, file hash, page count, text/OCR quality, pagination, completeness, and role: canonical copy, alternate, summary, or derivative. Never transfer a quotation's page number between editions.

Current identities are recorded in `16-bibliography-register.md`.
