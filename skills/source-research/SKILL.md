# Source Research
## Purpose
Build a traceable evidence set without confusing discovery aids with authorities.
## When to Use
For a new research question, source gap, or proposed bibliography addition.
## Required Inputs
Exact question, target section, needed claim/evidence type.
## Sources to Read First
Research Bible 05, 06, 09, 10, 14, 16; existing repository files.
## Procedure
Search registers for prior work; identify the appropriate source tier; consult primary texts first for authorial claims; find scholarly competitors/critics; capture full provenance, relevant passages, context, and contrary evidence; update files 09, 10, 14–16.
## Evidence Rules
Search snippets and summaries are discovery only. Never infer bibliographic fields. Label epistemic status.
## Output Format
Question; search scope; source records; findings by claim; disagreements; gaps; register updates.
## Quality Gates
Authority fits claim; source is read beyond snippet/abstract where needed; location and edition recorded; counterevidence sought.
## Failure Conditions
Paywall/inaccessible text, unstable provenance, missing page/context, or only tertiary support: report and mark unverified.
## Prohibited Behaviors
Inventing sources; citing a summary for Fukuyama when the book is available; padding bibliography.
## Completion Criteria
The question has adequate primary and scholarly evidence or a documented unresolved gap.
