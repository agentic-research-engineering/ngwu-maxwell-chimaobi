# Source Synthesis
## Purpose
Build a defensible account from sources without artificial consensus.
## When to Use
When a claim or section depends on several authors, disciplines, or cases.
## Required Inputs
Synthesis question, source records, extracted evidence.
## Sources to Read First
Research Bible 05, 06, 09, 14–16; original source contexts.
## Procedure
Group sources by question/claim; compare definitions, methods, evidence, scope; weight authority for the claim type; state agreements and genuine disagreements; explain resolution criteria or preserve contestation; derive only warranted synthesis.
## Evidence Rules
Attribute every position; distinguish source consensus from project inference.
## Output Format
Question; convergence; disagreement; methodological differences; synthesis; residual uncertainty; claim updates.
## Quality Gates
Minority/contrary evidence considered; no source loses qualifiers; inference is labeled.
## Failure Conditions
Sources are not commensurable or have not been read sufficiently.
## Prohibited Behaviors
Vote-counting, laundering tertiary claims, or merging distinct concepts.
## Completion Criteria
Readers can trace the synthesis back to each source and see unresolved disputes.
