# Comparative Philosophy
## Purpose
Produce defensible comparison without flattening differences.
## When to Use
Especially section 3.4 and civilizational/philosophical comparisons.
## Required Inputs
Comparison question, shared dimensions, primary texts for each party.
## Sources to Read First
Research Bible 06, 07, 12, 13; each thinker's primary text before Fukuyama's characterization.
## Procedure
Define the comparison dimension; identify each text's genre/aim; reconstruct each independently; compare only commensurable claims; distinguish direct disagreement, different vocabulary, and different project; test Fukuyama's portrayal; record asymmetry and limits.
## Evidence Rules
Use `[PRIMARY-OTHER]` for thinkers' own claims and `[FUKUYAMA]` for his reading; never merge them.
## Output Format
Dimension matrix; independent positions; similarities/differences; methodological limits; implications.
## Quality Gates
Every position has primary support; shorthand such as “noble savage” is scrutinized.
## Failure Conditions
Missing primary text or comparison rests only on a secondary portrayal.
## Prohibited Behaviors
Anachronism, false equivalence, civilizational essentialism.
## Completion Criteria
The comparison clarifies a philosophical issue and its limits are explicit.
