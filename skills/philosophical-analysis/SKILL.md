# Philosophical Analysis
## Purpose
Turn textual and historical findings into disciplined philosophical analysis.
## When to Use
For concepts, reconstructed arguments, objections, implications, or Chapter Five evaluation.
## Required Inputs
Precise target claim, verified evidence, evaluation criterion.
## Sources to Read First
Research Bible 04, 06, 07, 09, 11; source passages and relevant scholarship.
## Procedure
Define terms; reconstruct premises, assumptions, evidence, mechanism, conclusion; test validity and equivocation; identify normative/descriptive moves; steelman objection and response; state the residual conclusion proportionately.
## Evidence Rules
Label interpretation/inference/researcher thesis; historical evidence must be independently qualified.
## Output Format
Claim; reconstruction; assumptions; analysis; objection; response; residual assessment; evidence/gaps.
## Quality Gates
No category collapse; objection targets the actual claim; conclusion does not outrun evidence.
## Failure Conditions
Key premise or concept remains undefined/unsupported.
## Prohibited Behaviors
Straw men, rhetorical verdicts, naturalistic leaps, or treating contested readings as fact.
## Completion Criteria
The analysis is valid, source-grounded, qualified, and ready for claims-register entry.
