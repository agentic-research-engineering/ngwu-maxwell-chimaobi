# Citation Verification
## Purpose
Prevent fabricated, misplaced, or edition-mismatched citations.
## When to Use
Before adopting quotations/citations and during every audit.
## Required Inputs
Claim or quotation, citation, exact source copy, required citation style if known.
## Sources to Read First
Research Bible 05, 06, 15, 16; cited source and title/copyright pages.
## Procedure
Confirm source identity; locate wording; compare exact text; read surrounding context; record print and PDF page; test paraphrase entailment; verify bibliographic fields from authoritative metadata; log result and correction.
## Evidence Rules
No transfer of pagination between editions; unresolved details receive `[VERIFY]`/`[CITATION NEEDED]`.
## Output Format
Item; source/edition; result; verified location; context; correction; ledger/register action.
## Quality Gates
Quotation exact; qualifiers preserved; citation supports the entire attached claim.
## Failure Conditions
Source inaccessible, OCR ambiguous, edition unidentified, or context contradicts claim.
## Prohibited Behaviors
Guessing pages/DOIs/publication data or citing search snippets.
## Completion Criteria
Each item is verified, corrected, or explicitly rejected/unverified.
